# 新海高人 App 打包指南（安卓 + iOS）

移动端界面已经做好，接口仍然连你现有的后端 `https://hailin-alumni-api.onrender.com`。
下面是把它变成手机安装包的完整步骤，全部在你自己电脑上执行。

## 一、准备

1. 在 Lovable 右上角点击 **Publish** 发布，拿到正式网址。
2. 用 GitHub 把项目同步到本地，`npm install`。
3. 打开 `capacitor.config.ts`，把 `server.url` 换成第 1 步的正式网址。

> 说明：App 外壳是原生的（有图标、启动页、状态栏、全屏体验），页面内容从你的正式网址加载，
> 这样以后改内容只要重新发布网页，App 不用重新上架。
> 如果希望页面完全打进安装包里离线运行，删掉 `capacitor.config.ts` 里的整个 `server` 字段即可。

## 二、生成原生工程（只做一次）

```bash
npx cap add android
npx cap add ios      # 需要 Mac
```

## 三、每次改动后同步

```bash
npm run build
npx cap sync
```

## 四、出安卓安装包（.apk）

需要安装 [Android Studio](https://developer.android.com/studio)。

```bash
npx cap open android
```

在 Android Studio 里：**Build → Build Bundle(s)/APK(s) → Build APK(s)**，
产物在 `android/app/build/outputs/apk/debug/app-debug.apk`，可直接发给别人安装。

上架/正式版需要签名包：**Build → Generate Signed Bundle / APK**，选 `Android App Bundle (.aab)`。

## 五、出 iOS 安装包（.ipa）

需要 Mac + Xcode + 苹果开发者账号（$99/年）。

```bash
npx cap open ios
```

在 Xcode 里选择 Team 签名，然后 **Product → Archive → Distribute App**。
没有开发者账号时，只能用数据线安装到自己的 iPhone 上做测试。

## 六、应用图标与启动图

- 图标源文件：`public/app-icon-512.png`
- 建议用 `npx @capacitor/assets generate` 一键生成各尺寸图标和启动图。

## 常见问题

- **App 白屏**：检查 `capacitor.config.ts` 的 `server.url` 是否可以在手机浏览器打开。
- **接口报错 / 数据不出来**：后端在 Render 免费套餐上会休眠，首次打开需等 30 秒左右唤醒。
- **安卓 9 以上无法访问 http 接口**：接口必须是 https（你现在已经是）。
